# Әдеби Астана — «Қаламгерлер жолы»

Бұл репозиторийде Астана қаласындағы 7 тарихи-мәдени аялдамаға арналған қазақша, орысша және ағылшынша ақпараттық сайт орналасқан.

## Аялдамалар
1. С. Сейфуллин мұражайы — [01.html](01.html)
2. С. Сейфуллин ескерткіші — [02.html](02.html)
3. «Үш би» — [03.html](03.html)
4. Жаяу Мұса — [04.html](04.html)
5. Абай — [05.html](05.html)
6. «Үш арыс» — [06.html](06.html)
7. Алаш қайраткерлері — [07.html](07.html)

## Файлдар
- Әр аялдама — жеке HTML файл.
- Дизайн: `style.css`.
- Үш тілдің мәтіндері мен тіл ауыстыру: `site.js`.
- Суреттер: түпкі буманың `stop-01.jpg`–`stop-07.jpg` файлдары.
- `index.html` алғашқы аялдамаға бағыттайды.

## Интернетке жариялау
[Settings → Pages](https://github.com/BakhtygulHAB/adebi-astana/settings/pages) бөлімінде **Deploy from a branch** → **main** → **/(root)** → **Save** таңдаңыз.

Жарияланғаннан кейін сайттың мекенжайы: https://bakhtygulhab.github.io/adebi-astana/ .

QR-кодтардың тұрақты сілтемелері `https://bakhtygulhab.github.io/adebi-astana/01.html`–`07.html` болуы керек. GitHub Pages қосылмайынша бұл мекенжайлардың ашылуы расталмайды.

**Ескерту:** 7-аялдаманың иллюстрациясын нақты ескерткіштің фотосуретіне ауыстыру қажет болуы мүмкін.
