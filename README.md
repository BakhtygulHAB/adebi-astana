## Файлдық құрылым
- `index.html` — үш бағыттың басты беті
- `01.html`–`07.html` — бірінші бағыт, `site.js` және `style.css` пайдаланады
- `r2-01.html`–`r2-06.html`, `r3-01.html`–`r3-04.html` — 2 және 3-бағыттың беттері, `route-extra.js` және `route-extra.css` пайдаланады
- `stop-01.jpg`–`stop-07.jpg` — 1-бағыт суреттері
- 2 және 3-бағыттың SVG көрнекі бейнелері нақты фотосурет емес

QR-кодтар сайтыңыздың тиісті `.html` мекенжайын қамтиды. Материалдар экскурсияның таныстыру мазмұны ретінде берілді; маршруттың географиялық дәлдігін және экскурсияға қолжетімділігін сапар алдында тексеріңіз.
